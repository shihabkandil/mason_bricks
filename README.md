# Mason Bricks

This repository contains custom [Mason](https://docs.brickhub.dev/) bricks created to make building Flutter and Dart applications easier.

## Available Bricks

### 🧱 Full Feature

A comprehensive brick to generate a complete feature module with clean architecture, including:
  - `presentation/` (screens & widgets)
  - `domain/` (entities & repository interfaces)
  - `data/` (models, repositories & implementations)
  - Clean separation of concerns

[View Brick README](./full_feature_brick/README.md)

### 🧱 Injected Feature

A powerful brick to generate a structured feature module, including:
  - `presentation/`(screens & widgets)
  - `cubits/` (logic)
  - `data/` (repository interface & implementation)
  - Dependency injection setup

[View Brick README](./injected_feature_brick/README.md)
